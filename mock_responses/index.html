    API Request + Response Examples¶

    1️⃣ API: GET /messages/unread¶

    Purpose: Fetch unread messages for inbox list (system + bulk).

    Example Request¶

    GET /messages/unread?page=1&pageSize=20
Authorization: Bearer <JWT>

    Example Response¶

    {
  "page": 1,
  "pageSize": 20,
  "totalUnread": 4,
  "messages": [
    {
      "messageId": "12345",
      "title": "Address Change Confirmation",
      "summary": "Your address has been updated successfully",
      "type": "system",
      "status": "unread",
      "timestampUtc": "2025-12-04T09:15:00Z",
      "category": "Account",
      "actions": ["acknowledge"],
      "pushNotification": true
    },
    {
      "messageId": "67890",
      "title": "Dividend Applied",
      "summary": "December dividends applied to your portfolio",
      "type": "bulk",
      "status": "unread",
      "timestampUtc": "2025-12-04T08:00:00Z",
      "category": "Finance",
      "actions": ["download"],
      "pushNotification": false
    }
  ],
  "hasMore": true
}

    Notes¶

    • UI loads pages incrementally
    • Unread count reflects persisted state
    • Local cache allowed, but must refresh on resume

    2️⃣ API: GET /messages/unread (Degraded Mode)¶

    Purpose: Bulk API failed — inbox still loads using system messages.

    Example Response¶

    {
  "totalUnread": 2,
  "partialResult": true,
  "messages": [
    {
      "messageId": "88888",
      "title": "Statement Ready",
      "summary": "Your statement is available for download",
      "type": "system",
      "status": "unread",
      "timestampUtc": "2025-12-03T12:10:00Z",
      "category": "Finance",
      "actions": ["download"],
      "pushNotification": false
    }
  ]
}

    Notes¶

    • partialResult=true signals degraded mode
    • UI should still operate normally
    • Logging mandatory for root-cause traceability

    3️⃣ API: POST /message-detail¶

    Purpose: Retrieve full message content for detail view.

    Example Request¶

    {
  "userId": "U100001",
  "messageId": "12345"
}

    Example Response¶

    {
  "messageId": "12345",
  "title": "Address Change Confirmation",
  "content": "Your address has been successfully updated and no additional actions are required.",
  "type": "system",
  "status": "unread",
  "timestampUtc": "2025-12-04T09:15:00Z",
  "localizedTimestamp": "04 Dec 2025, 09:15 AM",
  "category": "Account",
  "actions": ["acknowledge"],
  "pushNotification": true,
  "metadata": {
    "changeType": "profileUpdate",
    "requiresAcknowledgement": true
  }
}

    Notes¶

    • Ownership validation enforced
    • Content may include legal wording or formatted text
    • UI should optionally show metadata-driven actions

    4️⃣ API: POST /mark-message-read¶

    Purpose: Persist read state + reduce unread count.

    Example Request¶

    {
  "userId": "U100001",
  "messageId": "12345",
  "returnUnreadCount": true
}

    Example Response¶

    {
  "success": true,
  "unreadCount": 3
}

    Notes¶

    • Must update UI immediately (optimistic update)
    • Reconcile after next fetch
    • Prevent invalid transition (cannot "unread")

    5️⃣ API: POST /mark-message-read (Already Read)¶

    Purpose: Demonstrates valid read state constraints.

    Example Response¶

    {
  "success": false,
  "reason": "MessageAlreadyRead",
  "unreadCount": 3
}

    6️⃣ API: POST /message-detail (Security Violation)¶

    Purpose: Ownership enforcement

    Example Response¶

    {
  "error": "MessageNotOwned",
  "statusCode": 403,
  "message": "The requested message does not belong to the authenticated user"
}

    7️⃣ API: GET /messages/unread With Filters¶

    Purpose: Narrow inbox by category or status

    Request¶

    GET /messages/unread?status=unread&category=CorporateAction&page=1&pageSize=20
Authorization: Bearer <JWT>

    Response¶

    {
  "page": 1,
  "pageSize": 20,
  "filters": {
    "status": "unread",
    "category": "CorporateAction"
  },
  "totalUnread": 6,
  "messages": [
    {
      "messageId": "99123",
      "title": "Corporate Restructuring Notice",
      "summary": "Corporate restructuring that affects your portfolio",
      "type": "bulk",
      "status": "unread",
      "timestampUtc": "2025-11-30T11:00:00Z",
      "category": "CorporateAction",
      "actions": ["view"],
      "pushNotification": true
    }
  ],
  "hasMore": true
}

    8️⃣ API: POST /mark-message-read — Offline Queue¶

    Purpose: Offline-safe mutation

    Response¶

    {
  "success": true,
  "syncState": "queued",
  "localCacheUpdated": true,
  "messageId": "99123"
}

    Notes¶

    • Local UI marks read immediately
    • Sync occurs on reconnect
    • Must reconcile unreadCount on next fetch
